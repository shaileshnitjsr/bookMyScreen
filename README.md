# 🎬 BookMyScreen

A modern full-stack Movie Ticket Booking System built with React, Node.js, Express, MongoDB, Redis, Socket.IO, and Razorpay. The application provides secure authentication, real-time seat locking, online payments, role-based access control, and a responsive user interface.

---

## ✨ Features

- 🔐 JWT Authentication & Authorization
- 🎬 Movie Management
- 🏢 Theatre Management
- 🎟️ Show Scheduling
- 🪑 Real-Time Seat Locking using Socket.IO
- 💳 Razorpay Payment Integration
- 📍 Theatre-wise Show Listings
- 📱 Responsive UI
- 🔄 Redis-based Seat Locking
- 🛡️ Role-Based Access Control (Admin & Customer)

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/shaileshnitjsr/bookMyScreen.git
```

### Backend

```bash
cd bms-backend
npm install
npm run dev
```

### Frontend

```bash
cd bms-frontend
npm install
npm run dev
```
